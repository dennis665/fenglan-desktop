# 2D 桌面魔法寵物 (Desktop Mascot) 使用說明書

歡迎召喚您的專屬 2D 桌面魔法寵物！本專案是一款兼具桌面陪伴、電腦狀態監控、影音播放與快捷檔案開啟的多功能 2D 桌寵互動程式。

---

## 🌟 核心特色

1. **透明與穿透視窗**：角色完美立於桌面上，背景完全透明；滑鼠移至空白透明處時會自動穿透（不影響點擊桌面其他視窗或程式）。
2. **重力下墜與掙扎**：滑鼠左鍵可抓起寵物隨意拖動（寵物會開心跳躍或掙扎晃動）；放開滑鼠後會因重力加速度平順掉落回螢幕底部。
3. **右鍵選單標題動態化**：右鍵選單頂部標頭會即時跟隨當前啟用的寵物動態變更（例如：`利姆路選單`、`魔法小貓選單`）。
4. **⚡ 快捷開啟檔 (Quick Executable Launcher)**：
   * 支援 **🔒 私人設定 (Private)** 與 **🌐 公開設定 (Public, 推至 Git)** 雙模式隔離存取。
   * **分類摺疊與數量標籤**：分類支援一鍵摺疊/展開，並即時顯示內部項目數量標記與記憶摺疊狀態。
   * **滑鼠左鍵拖曳排序與跨分類移動**：按住滑鼠左鍵可任意調整分類順序、分類內項目順序，甚至**跨分類拖曳搬移項目**。
   * **前置檔案瀏覽與安全容錯**：點擊 `📂 瀏覽` 會將原生檔案選擇器亮在最前面；若檔案路徑不存在，會以寵物對話泡泡提醒 `⚠️ 無法開啟檔案`，絕不卡死崩潰。
5. **精準 CPU RAM / GPU VRAM 實時區分監控**：
   * 右鍵選單最下方即時區分顯示 `💾 CPU: XX MB | 🎮 GPU: XX MB`。
   * 採用多處理序轉換係數，與 Windows 工作管理員欄位數據 **100% 精準 1:1 完全對齊**！
6. **影音播放器與視覺頻譜**：內建影音播放器，支援自訂影音檔案（`.mp3`, `.wav`, `.mp4`, `.webm`, `.ogg`）上傳、動態 Canvas 音訊頻譜視覺化與單曲/全曲循環播放。
7. **系統過載警報與趣味對話**：定時監控 CPU 與記憶體使用率，過載時彈出趣味對話；可在選單中自由拖動滑桿自訂警告觸發閥值。

## 🎮 操控指南

### 1. 互動操作
* **滑鼠左鍵點擊**：寵物會跳起並播放專屬反應動畫（同時增加日常撫摸任務進度）。
* **滑鼠左鍵長按拖曳**：可以抓起寵物移動至螢幕任意位置。
* **滑鼠右鍵點擊**：彈出動態客製化選單，包含「日常任務」、「收藏庫」、「影音播放器」、「快捷開啟檔」、「警告閥值設定」、「開發者模式」、「重新啟動軟體」、「離開寵物」。

---

### 2. ⚡ 快捷開啟檔 (Quick Launcher Guide)
在右鍵選單中點擊 **「快捷開啟檔」** 即可打開管理面板：
* **🔒 私人設定 (不提交 Git)**：
  專用放置個人的本地開發路徑、私密指令與特定腳本（儲存於 `assets/private_launchers.json`，已被 `.gitignore` 隔離）。
* **🌐 公開設定 (提交 Git)**：
  專用放置團隊共享的開發軟體或開啟檔（儲存於 `assets/public_launchers.json`，會隨版本控制分發給團隊夥伴）。
* **操作說明**：
  * **一鍵執行**：點擊項目的 `▶ 執行` 即可啟動應用程式、開啟檔案或開啟網址。
  * **一鍵摺疊/展開**：點擊分類標題列可切換摺疊狀態，方便項目多時保持版面乾淨。
  * **拖曳排序/跨分類搬移**：用滑鼠左鍵按住標有 `≡` 的分類或項目列即可上下拖曳排序，或直接把項目拖進另一個分類中。

---

### 3. 🏰 召喚與收藏庫 (Collection Panel)
在右鍵選單中點擊 **「收藏庫」**（預設 100% 優先開至「角色切換」頁面）：
* **角色切換頁**：
  * 寬幅彈性排版 (`410px`) 搭配自訂金色捲動軸，支援長文字作品名稱完整顯示不重疊。
  * 點擊卡片上的「啟用角色」即可秒速切換桌面寵物！
* **動作展示頁**：
  * 查看並預覽目前等級，目前未開放等級新增功能。

---

### 4. 🛠️ 開發者模式 (Developer Mode)
在右鍵選單中點擊 **「開發者模式」**：
1. **動態對話框提示**：在中段「設定動作對話框文字」下方，會即時顯示 `目前套用: [當前生效的對話文字]`。
2. **自訂 WebP 動圖上傳**：選擇特定角色與動作後，可直接匯入自訂 `.webp` 動圖。
3. **新增自訂角色**：輸入角色作品與角色名稱，即可將新角色新增至收藏庫。

---

### 5. 🎬 影音播放器 (Media Player)
在右鍵選單中點擊 **「影音播放器」**：
* **影音上傳**：點擊「➕ 上傳影音」支援選取 `.mp3`, `.wav`, `.mp4`, `.webm`, `.ogg`。
* **畫面與頻譜**：播放影片時自動展開視訊畫面；播放音樂時自動帶入跳動頻譜視覺化。
* **刪除連動**：點擊 `🗑️` 刪除項目時，會同步將媒體檔案從硬碟實體刪除。

---

## 💻 系統警報與對話框

寵物會定時監控系統狀態，超過設定閥值時（可在「警告閥值設定」中自訂 CPU 與記憶體門檻）會發出警報：
* **CPU 使用率過高**：「*💦 主人！電腦好燙喔！目前 CPU 使用率高達 85%！快熱昏了喵！*」
* **記憶體不足**：「*💾 記憶體快被吃光光了！目前使用率 88%！快關掉一些沒用的分頁吧！*」
* **深夜提醒 (23:00 ~ 05:00)**：「*💤 已經是深夜了呢，主人該睡覺了，早點休息喔！*」

## 🚀 開發、測試與打包指南

### 🛠️ 1. 初始化與環境設定
1. 將專案根目錄下的 `.env.example` 複製一份並更名為 **`.env`**。
2. 修改 `.env` 中的開關：
   ```env
   # 是否啟用開發者模式選單 (true = 顯示, false = 隱藏)
   ENABLE_DEVELOPER_MODE=true
   ```

### 📥 2. 安裝套件
在專案根目錄執行：
```bash
npm install
```

### 🏃 3. 本地執行與測試
* **前台測試**：
  ```bash
  npm start
  ```
* **Windows 背景靜默啟動**：
  直接雙擊根目錄下的 **`啟動寵物.vbs`** 即可在背景靜默開啟寵物，不彈出命令行黑視窗。

### 📦 4. 打包成獨立免安裝 EXE
執行打包指令：
```bash
npm run build
```
* **打包過濾黑名單 (--ignore)**：打包指令會自動忽略 `dist/`、`scratch/`、`assets/private_launchers.json` (私人捷徑)、`assets/custom_media.json` (自訂歌單)、`assets/media/` (媒體檔案)、`.git`、`.vscode` 與 `.log` 紀錄檔，確保打包出來的綠色版軟體極致乾淨與輕量。
* **打包產出**：打包完成後會在 **`dist/fenglan-desktop-win32-x64/`** 資料夾中生成 **`fenglan-desktop.exe`**，雙擊即可獨立執行！
